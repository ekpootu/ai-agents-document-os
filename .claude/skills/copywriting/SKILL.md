# Conversion Copywriting Protocol & Skill

Adopted from the top-ranked open agent standard on **skills.sh** and **Agent Skills Hub** (`coreyhaines31/marketingskills/copywriting`), this skill guides AI agents in generating clear, persuasive, outcome-focused marketing and web copy that converts.

---

## 1. Golden Copywriting Principles

### Clarity Over Cleverness
- If forced to choose between clear and creative, **always choose clear**.
- Clearer positioning and copy directly drives:
  - **+81%** higher conversion rates.
  - **38%** shorter evaluation cycles.
  - **28%** lower customer acquisition cost.
- If a visitor has to stop to decipher a pun or vague metaphor, you have lost them.

### Benefits Over Features
- **Feature**: What the software or tool *does* (e.g., "Uses ReportLab and pdfplumber").
- **Benefit**: What that means for the human user (e.g., "Never see broken spreadsheet formulas or rejected contracts again").

### Specificity Over Vagueness
- ❌ Vague: *"Improve your agent's document processing workflow."*
- ✅ Specific: *"Stop silent formula wipeout in `.xlsx` and 0-byte corruptions in `.pptx` across 500-page pipelines."*

### Customer Language Over Company / Internal Jargon
- Never expose internal storytelling or outline tags as literal public copy!
- ❌ **Anti-Pattern (AI Slop)**: Labeling sections or menu links literally as *"The Pain"* or *"The Solution"*.
- ✅ **Proper Copywriting**:
  - Instead of *"The Pain"*: Use *"Why Document Operations in AI Agents Break"* or *"The Hidden Cost of LLM Document Hallucinations"*.
  - Instead of *"The Solution"*: Use *"A Deterministic Engineering Substrate for Real Documents"* or *"How Document OS Guarantees Zero Data Loss"*.

## 2. High-Converting Page Structure Blueprint

| Section | Customer Objective | Copywriting Formula |
| :--- | :--- | :--- |
| **Hero Headline** | Instant comprehension within 3 seconds | `[Achieve Outcome] Without [Major Frustration]` or `The [Category] That [Primary Benefit]` |
| **Subheadline** | Expand on how it works in 1-2 punchy sentences | `[Product] gives [Audience] [Capability], ensuring [Specific Guarantee].` |
| **Primary CTA** | Low friction, high clarity | `[Action Verb] + [What They Get]` (e.g., *"Install Document OS Free"*, *"Explore CLI Tools"*) |
| **Social Proof Pill** | Trust cue before scrolling | `"Trusted by 10,000+ developers"`, Star count, or test-backed badge |
| **Metrics Bar** | Quantitative credibility | 3 hard statistics: (e.g. `100% Formula Fidelity`, `0 Corrupt Files`, `5 Format Engines`) |
| **Feature Cards** | Connect capability to relief | Title: bold outcome. Description: 2 sentences showing exact prevention/gain |
| **How It Works** | Demystify complexity into 3 sequential steps | Step 1: Preflight Triage → Step 2: Protocol Engine → Step 3: Visual QA |
| **Objection Handling**| Remove friction and fear | Explicit FAQ or comparison grid (e.g., *"Why not just let the LLM write scripts?"*) |
| **Closing CTA** | Final decision trigger | Recap value + repeat primary action + risk-reversal guarantee |

## 3. High-Converting CTA Formulas

Avoid weak, generic CTAs:
- ❌ Avoid: *Submit, Click Here, Learn More, Get Started, Continue, Go.*

Use action-oriented, value-promising CTAs:
- ✅ *Download Official PDF Guide (v4.0)*
- ✅ *Install Free via PowerShell*
- ✅ *Explore CLI Commands*
- ✅ *Deploy Document OS to Your Agent*
- ✅ *View Live Interactive Demo*

---

## 4. The "Now You Can" Test

Before publishing any headline or feature description, run the sentence through the **"Now you can..."** filter:
- If the phrase sounds natural after "Now you can", it is benefit-driven:
  - *"Now you can process 500-page scanned financial reports without token budget exhaustion."* (Passed ✅)
  - *"Now you can modular architecture."* (Failed ❌ — that is a feature, rewrite to: *"Now you can swap format specialists without changing your agent's core prompt."*)

---

## 5. Standard Quality Checklist

Before finalizing any copy:
- [ ] Are all internal writing prompts/labels (like "The Pain", "The Solution") replaced with customer-facing headlines?
- [ ] Is there an active verb in every headline and button?
- [ ] Are there unnecessary exclamation marks? (Remove them).
- [ ] Does the copy address the ideal customer (AI agent developers, data teams, enterprise architects)?
- [ ] Are claims substantiated with technical specifics rather than buzzwords?
