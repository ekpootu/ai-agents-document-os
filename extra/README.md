# Extra Assets & Mockup Resources — Document OS

This directory contains supporting design assets, vector badges, and UI device mockups used for custom PDF compilation, book flip demonstrations, and marketing materials.

## Directory Structure

- `extracted_assets/`: High-resolution graphics and UI mockups:
  - `book_flip_mockup.jpg`: 3D hardcover publication book mockup with Socrates standard geometry.
  - `header_banner.png`: Corporate branding header for report covers.
  - `laptop_mockup.png`: Modern notebook display graphic showcasing Document OS in action.
  - `process_badges.png`: Vector badges denoting verification and format fidelity.
  - `shapes_callout.png`: Geometric brand callouts and visual accent elements.
  - `stacked_books.png`: Stacked volume graphics for publishing showcases.

## Usage
These assets are referenced by auxiliary scripts in `scratch/` (such as `scratch/build_book_flip_pdf.py`) and can be integrated into custom whitepaper or book publishing pipelines.
